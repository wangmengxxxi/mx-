# 独立 CPU 环境说明

本次实际运行路径为 `F:/研究生毕设/不完整多视图聚类/envs/imvc_cpu/python.exe`，使用 `-I` 参数。解释器和依赖均来自此独立目录。

- `environment.txt`：实际 conda 包与 pip 包清单。
- `environment_explicit.txt`：conda 管理的 Python/系统依赖显式清单。
- `environment_requirements.txt`：实际 pip distribution 元数据版本清单。
- `results/torch_copy_manifest.json`：本次 Torch 的独立复制路径、全部文件 SHA-256。

Torch 的 distribution 元数据版本是 `2.8.0`，运行时 `torch.__version__` 为 `2.8.0+cpu`。因此不能只凭 pip freeze 中 `torch==2.8.0` 推断安装了 CPU wheel。复建时先按 explicit 清单建立同版本 conda 解释器，再安装除 Torch 之外的 requirements；Torch 必须显式使用官方 CPU wheel（例如 `torch==2.8.0+cpu`，官方索引 `https://download.pytorch.org/whl/cpu`），或在同 Python 3.9.21 ABI 下执行本项目 `scripts/copy_cpu_torch.py`，复制本机现有 CPU 包并核对清单。不要把已有源环境作为 pip 安装目标。

本次为了避免重复下载 619.3 MB wheel，采用后者。复制真实文件而非硬链接/软链接；源 `F:/Anaconda/envs/pytorch` 只读。依赖单独安装，`pip check` 通过。实验入口在启动时隐藏 CUDA 设备、固定 `torch.device('cpu')`；没有 GPU 或 CUDA 包运行。

批处理进程为普通隐藏 Windows 后台进程，关机/重启会中断运行。恢复前应先确认原队列已经退出，避免同一 out 路径被两个进程并发写入。`run_batch.py` 复用已有完整 `result.json`，未完成的运行从头训练，不从半成品推断结果。正式汇总严格排除 smoke/benchmark。
