## 4. 方法、固定超参及标签隔离

- 所有方法读取相同缓存并先 L2 归一化，无标签特征变换。KM：sklearn KMeans，k=K，k-means++，n_init=10，max_iter=300，tol=1e−4，lloyd，random_state=seed。
- BAL：单个余弦线性头 768→K、无偏置，torch Linear 随机初始化，每次前向归一化权重，logits=10·cos；对 cos/0.05 施加 log-domain 均匀 Sinkhorn（3 次行列归一化），stop-gradient 软目标交叉熵。Adam lr=5e−4、betas=(0.9,0.999)、wd=0，cosine 日程，batch=1024，最后小批保留，固定最终100轮。不训练骨干、不新增图像增强；同一缓存特征产生目标与预测，是 SwAV 风格分配自训练基线，不是完整 SwAV 复现。
- P2OT_feat：官方 SemiCurrSinkhornKnopp 能独立接收 logits，故加入。原始求解器不改动，epsilon=0.1、gamma=1、stoperr=1e−6、最多1000次，semi_use=True；rho=0.1+0.9·exp(−5(1−step/total_steps)²)。头、初始化、打乱、优化器、100轮和最终检查点同 BAL，保留部分输运软目标的行质量，不逐行归一化目标。本次单头、无 logits memory bank、无双视图、无骨干微调；是模块适配，不是 P²OT 论文成绩复现。
- ORACLE_KM：在当前子集以标签计算各类 L2 特征均值，不再单位化类中心；以平方欧氏最近中心分配，Lloyd 迭代0次。只用于离线诊断，依赖真实标签。
- LP：sklearn 多项逻辑回归，L2 特征，C=1、lbfgs、max_iter=1000、tol=1e−4、截距开启、class_weight=None。在同一子集监督拟合并重代入评价，是表示可分性的监督参照，不是泛化精度，也不是无监督可达成绩。

标签仅用于按要求构造长尾、最终离线评价，以及明确标注的监督 ORACLE_KM/LP；KM/BAL/P2OT_feat 拟合函数只接收特征、K、seed，不接收真实类别或每类数量。没有用标签挑超参、轮次或检查点。

每组按最大样本正确数求一次全局 Hungarian 映射，ACC、各类召回、BA、macro-F1 与尾部召回共用该映射，子组不重新匹配。NMI 使用 arithmetic 平均，ARI/NMI 本身对编号不敏感。LP 也使用相同评价入口。

## 9. 判断边界

**按冻结规则：通过。** 本结论只覆盖单一 DINOv2 ViT-B/14、冻结特征、所选头及超参、转导式设定、CIFAR两个数据集与五个配对种子。强预训练语料与 CIFAR 的潜在重叠未独立审计，不能将本结果当成完全未知域的泛化证据。尾类在 CIFAR100 IR100 最少仅5张，其重代入监督结果尤其不能解释为尾部泛化。

ORACLE_KM 是使用真实类中心的操作性分配参照，不是任意聚类器的数学上界；若某个无监督结果超过它也不矛盾。LP 是带标签的重代入参照。即使规则通过，也只说明长尾下降和监督参照差距同时存在，不能单凭 oracle 差值证明一个可部署无监督方法一定能找回该差距；P2OT_feat 的配对收益是本次实际测试的无监督方法证据。若 P2OT_feat 不改善，必须保留这一负结果，不以其失败反推所有不平衡方法无效。BAL 同缓存自训练没有图像多视图约束，所见现象不能全部归因于均匀先验。

本次没有开发新方法、搜索超参或更换骨干，未因结果调整8/5个百分点阈值。既往两个方向目录保持只读。
